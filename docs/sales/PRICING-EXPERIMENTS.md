# Pricing Experiments — Phase 17 (paid beta only)

> These are tests, not permanent prices. Run **one test at a time**, record the
> result in the prospect database, and only change one variable per test.
> Reference point: Inc42 Pro ~₹1,499/month. Atlas must **not** compete solely on
> being cheaper (PRD §8).

## Plan grid

| Plan | Initial test | Notes |
| --- | ---: | --- |
| Free | ₹0 | search, basic filters, basic profiles, first 20–50 results |
| Founding Pro | ₹999 / month | early concierge customers, time-boxed |
| Normal Pro test | ₹1,499–₹2,499 / month | the real hypothesis |
| Team | ₹5,000–₹10,000 / month | only after Pro validates |
| Custom intelligence / data | ₹10k–₹1L+ per project | the concierge deliverable itself |

## What each test is measuring

| Test | Hypothesis | Metric |
| --- | --- | --- |
| Founding Pro ₹999 | early price-insensitive buyers pay for depth | conversion from discovery call → paying |
| Pro ₹1,499 | parity with Inc42 at our depth | conversion + churn |
| Pro ₹2,499 | willingness to pay for *verified* regulatory data | share choosing ₹2,499 |
| Custom ₹10k+ | B2B project demand | # paid projects, reorders |
| Team ₹5k–10k | multi-seat need | seat requests |

## Rules

1. One variable per experiment (price, plan name, or feature boundary — never all three).
2. Every price is communicated as a **temporary founding price**, reversible.
3. Invoice-only billing until P13 (no payment processor).
4. Log each experiment: dates, audience, price, conversion, verbatim reactions.
5. A gate criterion is only met with recorded evidence (VALIDATION-GATE.md §2).
