### Audit triage policy (E11)

Every gap cycle entry must be triaged by the same lens so the queue never
accumulates unowned work:

| Bucket | Meaning | Default owner | Action |
|--------|---------|---------------|--------|
| Buildable | Doable on the static architecture, no operator input needed | Next gap cycle | Ship with tests + gates green, then log 🟢 |
| Gated | Needs validation-gate evidence (P13–P17) or a new ADR | Product (operator) | Track in ROADMAP gating, never build early |
| Operator | Needs human access/accounts/review (O1–O7) | Operator | Keep in §3b / ROADMAP O-list, mirror to GitHub issues |
| Content | Editorial/data refresh or new original research | Content | Schedule by freshness policy (§3b) or plan cadence |

A gap is closed only when it lands in exactly one bucket with an owner, a
verification line, and a 🟢/🔴/🟡 status. Anything unclassified stays "open".
